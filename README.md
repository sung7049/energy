# ⚡ 에너지 장관 2050 (Energy Minister: 2050)
### 고등학교 통합과학 교육용 전력계통 정책 시뮬레이션 엔진 및 웹 실험실

본 프로젝트는 고등학교 통합과학 및 에너지 정책 교육을 위해 제작된 전력계통 시뮬레이션 엔진과 대화형 웹 기반 실험실입니다.

---

## 🚀 빠른 시작

### 1. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속하여 시뮬레이션 실험실을 직접 조작할 수 있습니다.

### 2. 자동화 단위 테스트 실행
```bash
npm test
```
모든 물리 법칙, 에너지 보존 법칙, ESS 순환 경계 조건 및 11개 검증 테스트를 Vitest로 즉시 검증합니다.

### 3. 프로덕션 빌드
```bash
npm run build
```

---

## 🛠 주요 구성 요소

1. **독립적 TypeScript 시뮬레이션 엔진 (`src/engine/`)**
   - React 의존성 없는 순수 TS 모듈
   - 4계절 대표일 $\times$ 24시간 급전 알고리즘
   - 엄격한 에너지 보존 및 ESS 순환 수렴 모델
   - 정책 파이프라인(건설 기간, 노후 퇴역, 기술 발전 학습곡선)
2. **시뮬레이션 실험실 UI (`src/lab/`)**
   - **국가 설정 패널**: 발전원별 설비용량(GW), ESS 용량(GWh), 수요 증가율 슬라이더
   - **중앙 그래프**: 24시간 수급 곡선, 재생E 출력제어, ESS SOC, 연간 발전원 비중, 2026~2050 다년도 추이
   - **분석 패널**: 실제 계산 수치에 근거한 자동 진단 해설
   - **시나리오 비교실**: 태양광 10GW vs 태양광 10GW + ESS 20GWh 등 정책 조합 비교표 및 그래프
3. **문서 자료 (`docs/`)**
   - [ENGINE.md](./docs/ENGINE.md): 수리 모델, 급전 알고리즘, 물리 법칙 상세 설명서
   - [LIMITATIONS.md](./docs/LIMITATIONS.md): 대표일 단순화 한계 및 향후 개선 과제
